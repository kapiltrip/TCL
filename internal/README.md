# Supporting files

The integrated [Day 1](../day-1.md), [Day 2](../day-2.md), [Day 3](../day-3.md), and [Day 4](../day-4.md) pages are the study material. Day 4 practice reaches `regsub`; its assignments remain. This folder contains the files those pages use.

| Folder | Purpose |
| --- | --- |
| `images/` | Original question and console screenshots, displayed inline in the day pages |
| `scripts/` | Runnable day scripts, Tcl/Tk greeting examples, and Windows launchers |
| `sources/` | Original [Days 1–3 transcript](sources/console-session.txt), [Day 4 list session](sources/console-session-2026-10-04-lists.txt), and [Day 4 foreach through regsub session](sources/console-session-2026-10-04-regexp-regsub.txt) |
| `runtime/` | Portable Tcl/Tk interpreter and libraries; only [installation details](runtime/installation.json) are tracked |

Local `.setup/` installer files and `.qa/` verification data are excluded from Git. Run the launchers as described in the [main index](../README.md#run-the-code).
