# Supporting files

The integrated [Day 1](../day-1.md), [Day 2](../day-2.md), [Day 3](../day-3.md), [Day 4](../day-4.md), [Day 5](../day-5.md), and [Day 6](../day-6.md) pages hold the study material. [ideas.md](../ideas.md) connects Assignments 17–33 to those lessons through detailed approaches rather than completed answers. This folder contains the supporting files.

| Folder | Purpose |
| --- | --- |
| `images/` | Original question and console screenshots, displayed inline in the day pages and `ideas.md` |
| `scripts/` | Runnable day scripts, Tcl/Tk greeting examples, and Windows launchers |
| `sources/` | Original [Days 1–3 transcript](sources/console-session.txt), [Day 4 list session](sources/console-session-2026-10-04-lists.txt), [Day 4 foreach through regsub session](sources/console-session-2026-10-04-regexp-regsub.txt), [Day 5–6 arrays and loops session](sources/console-session-2026-10-05-arrays-loops.txt), and [Day 4–6 question text](sources/day-4-6-assignment-questions.json) |
| `runtime/` | Portable Tcl/Tk interpreter and libraries; only [installation details](runtime/installation.json) are tracked |

Local `.setup/` installer files and `.qa/` verification data are excluded from Git. Run the launchers as described in the [main index](../README.md#run-the-code).
